## PayPal AI Hackathon snapshot

- Snapshot deadline: 12 November 2026, 8:00 PM GMT.
- Core requirement: meaningful PayPal developer-platform integration plus meaningful AI.
- Functional build: hosted demo or complete run instructions; static mockup is insufficient.
- Submission snapshot calls for a public open-source repository with visible licence and an under-three-minute public YouTube demo.
- Strategy: compete for overall placement, Best Use of PayPal + AI and Best Use of Agentic Commerce with one coherent PayPal sandbox journey.
